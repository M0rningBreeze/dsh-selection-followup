为什么是「旁边」

问归问，别把主线搅了

在主对话里追问会改掉后续对话的注意力，还会留下永远用不上的记录。这个插件把追问挪到旁边一张卡里， 而它读什么、带多少上下文，由你当场决定。

🪟

浮层卡片，不占版面

贴着你选中的文字浮出，右侧优先、放不下自动翻到左侧；不挤压主界面，也不抢侧栏。

🎚️

上下文你说了算

默认只带选中的那一段；需要时才切「近 5 轮」或「全部」，按问题编号带上 Q1、Q2…

🧾

零写入

不新建会话、不写会话日志、不占侧栏列表。关闭卡片即清空，主对话完全不受影响。

📝

回答按 Markdown 渲染

粗体、列表、代码块、链接都正常显示；长回答在卡片内滚动，随时可以停止。

🎯

问题会跟着内容变

选代码给「解释 / 找问题 / 加注释」，选英文给「翻译 / 解释 / 说简单点」，选段落给「展开 / 举例」。

🪞

和官方同一套视觉

24px 圆角、34px 圆形蓝色发送键、18px 胶囊——几何和配色对齐 DeepSeek 官方聊天前端。

三步

从读到问，两次操作

不用离开阅读位置，不用碰剪贴板。

01

划选一段

在主对话里选中想深究的那句话、那段代码或那段英文。

02

右键「追问」

原生右键菜单不会弹出，卡片直接出现在选区右侧，顶部就是那段原文。

03

问一句就好

点一个建议问题，或自己敲一句回车；回答说卡在卡片里流式出现。

安装

两分钟装上

插件是纯本地目录，没有任何构建步骤或第三方依赖。

方式一 · 界面安装

下载或克隆本仓库，然后在 DSH 的「插件」页里：

插件 → 添加插件
粘贴 selection-followup 目录的绝对路径 → 安装

输入框支持包名、GitHub 地址或本地目录路径；本地目录没有选择器，粘贴路径即可。

方式二 · 命令行

已装 DSH CLI 时，一条命令装进当前 profile：

dsh plugin add /path/to/selection-followup

也可以指向 tarball 或 npm 包名；安装后重启 DSH 生效。

它的边界

  • 纯问答：不能读文件、跑命令、调用工具；需要那些能力请回主对话。
  • 选中文字和所选上下文会发给模型，走主对话同一条模型链路。
  • 追问内容不落盘，关闭卡片或刷新即丢失。
  • 卡片暂不支持拖动和缩放。
